🧩 CodeCrux

Crack the code. Trust the clues.

CodeCrux is a daily 4-digit number guessing puzzle game inspired by logic-based deduction games. Players get 7 chances to guess a unique 4-digit number, with feedback after each attempt showing how many digits are correct and how many are misplaced.


🚀 Features
  🔢 Daily unique 4-digit puzzle
  🎯 7 attempts per game
  ✅ Feedback system (Correct & Misplaced digits)
  📱 Fully responsive mobile UI
  💾 Persistent game state (resume anytime)
  🎉 Confetti animation on win
  🔒 No duplicate digits allowed
  🧠 Tech Stack
  
Frontend: React Native
Framework: Expo
State Management: React Hooks (useState, useEffect)
Storage: AsyncStorage (local persistence)
Animations: react-native-confetti-cannon
Language: JavaScript / TypeScript (TSX compatible)


🛠️ Installation & Setup
1. Clone the repo
    git clone https://github.com/your-username/codecrux.git
    cd codecrux
2. Install dependencies
    npm install
3. Run the app
    npx expo start

Scan QR using Expo Go app on your phone.

📱 Run on iPhone
Install Expo Go from App Store
  Run npx expo start
  Scan QR code

🧩 Game Rules
Guess a 4-digit number
All digits must be unique
After each guess:
✓ = Correct digit in correct position
↺ = Correct digit in wrong position
You have 7 attempts
